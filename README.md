# Fashion Dream 3D

Game thời trang 3D mini chạy trên trình duyệt, dùng Three.js qua CDN.

## Chạy thử
Mở `index.html` bằng trình duyệt có kết nối Internet. Nếu trình duyệt không cho chạy file trực tiếp, dùng VS Code + Live Server.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html` (và README này nếu muốn).
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn nhánh `main`, thư mục `/(root)`, rồi Save.
6. Chờ GitHub tạo đường dẫn Pages.

## Có gì trong demo?
- Nhân vật 3D dựng bằng hình khối Three.js.
- Tùy chỉnh màu trang phục, tóc, giày và phụ kiện.
- Xoay nhân vật bằng thao tác kéo/chạm.
- Hiệu ứng sao lấp lánh và thử thách chấm điểm outfit.

Lưu ý: đây là bản demo khởi đầu; nhân vật dùng mô hình 3D dựng bằng hình khối, chưa phải model thời trang chi tiết có rig/animation chuyên nghiệp.
